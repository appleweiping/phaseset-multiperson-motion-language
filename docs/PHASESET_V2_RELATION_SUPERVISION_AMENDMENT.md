# PhaseSet-V2：已有标注优先，机器关系监督单独披露

2026-09-27，项目负责人明确表示没有两位新标注者，要求使用 LLM 或已有标注
继续研究。本修订取代“必须等到两位新标注者才能继续”的执行要求，不追溯
改写原 handoff，不伪造人工记录，也不改变当前 87 阶段、12 pilot、三 seed、
300 GPU-hours 上限或已有成本。对应机器可读规则见
[supervision contract](../configs/phaseset_v2_relation_supervision.json)。

## 主结果不换 ground truth

确认性 full-gallery motion–language retrieval 继续使用官方原始人工 holistic
文本、既定 parent 正例身份和组件划分。机器改写、机器融合、伪负例不进入
human-only 主 gallery。已有人工正例不自动证明一个反事实句子为假：同一长
capture 内可能同时发生它们，缺少一句描述也不等于事件不存在。

优先复用已有、许可适配且语义确实匹配的显式关系标注；本修订不声称官方
holistic 描述已经提供两人独立的真/假关系标签、actor/time grounding，或已经
找到额外资产。不得为补标签无声增加数据集或训练阶段。

## LLM 可提供弱监督，不是独立真值

可用 GPT-5.6-Sol 读取同一训练 parent 的官方人工文本，提出带来源的最小
关系对比。它不读取模型分数、骨架/频谱/phase、held-out 或最终 test 文本。
固定 prompt、模型与解码参数、候选数及不依赖分数的纳入/拒绝规则，在相应
pilot/训练前一次冻结；保留机器来源、原人工文本依据、输出及排除记录。
无法判断的项不强行打真/假标签。不通过反复改写刷挑战集数量或模型成绩。

若实施机器 CF 训练，其标签身份为 `machine_caption_contradiction`，只提供
明确披露的弱训练监督。full 与适用的机制对照使用相同弱监督池和预算，A8
仍关闭 CF 目标；不可将机器推断塞进原 human-only `verified_false=True`
接口。需要独立的弱标签接入和计数，原真实人工接口与旧测试保留。当前修订
只是输入/结论合同，**弱 CF 生成与训练接入尚未实现或资格通过**，不能据此
宣称正式训练已启动。无 CF 的基础模型与独立开发工作不再等新真人标注。

## 评估与结论边界

机器辅助关系挑战只能单独标为探索性：报告其标签来源和覆盖/排除情况，
不能称为人工核实的关系准确率，更不能以模型对机器标签的一致性证明模型
理解真实动作。具有真正匹配的已有独立标注时，才按其真实适用范围另报结果。

历史“200 对、100 capture、8 组件、两名盲人类审核”和挑战提升 5pp 目标不由
机器数量替代；没有匹配独立标签时记为 **UNASSESSABLE**。这取消继续等待
真人的执行阻碍，不把原全部机制成功标准偷偷降格为已通过。官方人工检索
结果、预登记的结构/方向消融仍可支持各自的实证结论；CF 对 A8 的检索增益
只能支持弱监督训练的效用，不单独支持人类核实的关系理解或 grounding。

最终论文必须反映实际证据：弱关系监督和没有独立真人挑战是明确限制。
负结果和证据不足仍交付完整代码、真实结果、统计与论文，不刷 seed/test。
